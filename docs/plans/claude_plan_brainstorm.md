### 渲染（重写 `husky_view.c`，直接写帧缓冲）

- 自己实现正确的 8 位 alpha 混合（逐通道），不经过引擎 `blend565()`，因此不需要二值 alpha 和抖动。
- 精灵绘制：支持缩放、水平翻转、整数行偏移的切变（狗身向弯内倾），alpha 为 0 的整段跳过，不透明像素直写。
- 地面：天空到地平线下约 20 px 用底图；其下逐行透视投影，路面按 (横向, 距离) 采样车辙纹理，车辙随行进流动并跟着弯道曲线弯；路外采样松雪纹理；近地平线一段和底图交叉淡化。
- 左右弯：道路中心曲线 `center(y) = 240 + turn × K × ahead²`，由 `turn` 驱动，K 按左、右弯底图里道路的弯曲量标定，天空随 `turn` 小幅横移。左右弯底图的道路是静态的，直接换图会让车辙停住、转弯跳变，所以只拿它们做形状标定和效果对照。
- 路边物件：每个距离槽位用确定性哈希决定左右是否放树、哪种树、离路距离、是否放灯，两侧不再镜像对称；物件高度超过屏幕约 1.6 倍时剔除，避免近处贴图放大出马赛克。
- 层次顺序：天空/地面 → 物件（远到近）→ 第 1 对狗（最远）及其雪尘 → 第 2 对 → 第 3 对 → 绳子穿插（绳在狗身前后按对排序）→ 扶手。
- 雪尘：固定 256 个粒子池，按每只狗的步相在后爪落地帧发射。两类粒子：雪花（小、亮、抛物线向后上飞）和雪尘（大、半透明、扩散变淡）。速度为 0 时停止发射。

## 目标

在 ESP-Mosaico（esp32s31，480×480 RGB565）上做一款第一人称哈士奇雪橇竞速游戏。操控用交互子板和 IMU。一张地图跑 3 圈，地图只决定路线，场景一直是雪地。

## v1 玩法方向（用户最新意见，待细化）

- **纯奔跑**：赛道上没有金币、道具和障碍，画面就是狗狗们欢快地跑。
- **尽量不减速**，高分体现在一路保持速度，跑出风雪扑面的热情感。
- 暂定"热情值 (heat)"机制，草案如下：
  - 在雪道上跑、不刹车：热情值缓慢上涨，约 20 秒涨满。
  - 冲出雪道进入深雪区：热情值下降较快，速度也降下来。
  - 普通刹车会扣热情值；刹车加转向触发甩尾过弯，甩尾不扣热情值，松开后有一小段加速。
  - 热情值越高，最高速越高（暂定 14 → 23 m/s），雪粒子越密，风雪越扑面，狗狗步频越快。
  - 分数 = 跑过的距离 × (1 + 3 × 热情值)。
- 保留：转向、跳跃、刹车、冰面打滑、甩尾。
- 3 圈结算：总时间、最佳圈速、分数、最高热情值。

**待用户细化的问题**

1. 热情值的涨落规则和数值是否合适？风雪感要分几档表现？
2. 跳跃在"什么都没有"的赛道上有什么用？是纯表演，还是起跳和落地也影响热情值？
3. 冰面和甩尾第一版是否保留？
4. 高分的表现形式：分数数字、档位（比如 微风 / 风雪 / 暴风雪），还是用画面强度直接体现？
5. 结算和排名需要哪些信息？最佳记录是否存到 NVS？

## 操控（用户已确定：两套都做，开局可切换）

交互子板只有左右两个键，另有 PIR、环境光、6 颗 WS2812 和红外。

- 模式 A（体感）：IMU 左右倾 = 转向；子板左键长按 = 刹车；子板右键 = 跳跃。
- 模式 B（按键）：子板左/右键 = 转向；双键同时短按 = 跳跃，双键长按 = 刹车；IMU 前倾/后仰作为辅助。
- 两种模式都保留触屏兜底。Host 键盘：A/D 转向，W/Space 跳，S 刹车，Q/E 模拟子板左右键，Enter 重开，P 暂停。
- LED 和 PIR 互动留到后续版本。

## 技术依据

- 参考引擎示例 `submodule/raylib-lite-engine/examples/neon_rift_rally/`：曲线赛道投影、分层全景、3 圈计时、IMU 横滚转向（死区约 6°，倒计时期间校准）、NVS 记录。
- 交互子板驱动在 `submodule/esp-mosaico-bsp/components/mosaico_module_interact/`（`mosaico_interact_read_inputs` 读左右键、PIR、光照，`led_write` 控 6 灯）。它依赖整套 `esp-mosaico-bsp` 和 `mosaico_module_mgr`，和引擎的 Board Manager 板级适配能否共存要在设备构建时验证。这是主要集成风险。
- Atlas 规格：方形网格 cell，`alpha_mode` 可选 `smooth` / `binary` / `opaque`。原生构建用 IDF 的 Python 跑 `prepare_*.py` 钩子，那个环境没有 Pillow，所以生成好的 PNG 要提交到仓库，钩子在缺少 Pillow 时直接跳过。
- Host 仿真注意事项：
  - 本机 Apple clang 21 编译 pinned 引擎时，`-Werror` 会因 `misleading-indentation` 报错。目前在 scratchpad 里放了一个 `cc` 包装脚本，加上 `-Wno-misleading-indentation` 绕过，没有修改子模块。
  - 需要用 `projects/husky_sled_race/.venv/bin/python` 运行，这个环境有 Pillow。
