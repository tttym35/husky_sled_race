# 哈士奇雪橇游戏：Codex Plan 头脑风暴

日期：2026-11-19

## 核心方向

六只哈士奇拉着雪橇欢快奔跑，玩家用交互子板参与驾驶，分数越高，奔跑越热烈，风雪扑面的感觉越强。

重点是“纯 kuku 跑”的快乐：即使一路没有东西可捡，光看六只狗狗欢快奔跑、亲手带它们转弯，也愿意完整跑完三圈。

本文为设计计划，具体数值、操作映射与技术路线待设计确认和设备验证后确定。

## 一、第一版体验

- 第一人称雪橇视角，底部露出扶手。
- 六只哈士奇，三排、每排两只。最前排允许自然遮挡。
- 沿用参考视频的增强写实方向：写实犬队、蓝紫雪地、积雪树林、暖黄灯光。
- 一个固定闭环地图，跑完三圈结束。
- 雪橇自动前进，全程顺畅奔跑。
- 第一版画面保持纯粹，金币、道具、障碍和对手暂缓。
- HUD 只保留小尺寸分数、圈数和简洁路线图。

## 二、先把“狗狗跑得开心”做好

犬队是视觉制作的第一优先级。

| 部位 | 计划表现 |
| --- | --- |
| 奔跑动作 | 六只狗步伐略有错落，身体随步态起伏 |
| 耳朵和尾巴 | 自然颠动、摆动，强化欢快感 |
| 犬队队形 | 保持三排结构，转弯时沿路径依次跟进 |
| 牵引绳 | 连接正确，奔跑时有张力和轻微摆动 |
| 脚下积雪 | 随踩踏扬起粉雪，速度越快越明显 |
| 雪橇视角 | 轻微颠簸、过弯倾斜、落地缓冲 |

先制作一套可信的奔跑循环，再扩展转向、加速和腾跃状态。避免六只狗完全同步，产生复制粘贴的感觉。

## 三、交互方案

| 输入 | 游戏反馈 |
| --- | --- |
| 子板左／右 | 控制雪橇转向，有轻微惯性 |
| IMU 左右倾斜 | 作为另一种转向模式，可校准中立位置 |
| 跳跃 | 犬队和雪橇完成轻快短跳，着地扬雪 |
| 刹车 | 平滑减速，风声和扬雪同步减弱 |

按键与 IMU 转向可切换。IMU 设置死区、平滑和倾角上限，确保手持时稳定。

路线提供轻度引导，玩家可以自然跟弯、调整位置。靠近路边时柔和修正，让奔跑连续。具体按键映射在读取交互子板配置后确定。

## 四、分数驱动“撒欢感”

持续奔跑自然涨分，顺畅驾驶给予少量额外奖励。刹车保留已有分数，方便随时放慢节奏。

分数决定犬队的热情等级，当前速度决定即时风雪强度。这样高分时刹车，画面也会自然安静下来。

| 阶段 | 表现 |
| --- | --- |
| 欢快出发 | 轻快步态、少量扬雪、清晰雪林和铃声 |
| 尽情奔跑 | 步频与速度适度提高，近景后掠增强，风声渐强 |
| 全队撒欢 | 犬队跑动更有力量，迎面雪粒增多，两侧雪雾升起 |

速度、镜头晃动和雪粒密度都设上限。中央区域始终看得清犬队和道路，热烈感主要由画面边缘、声音和近景速度共同营造。

## 五、地图与场景复用

第一张地图采用宽松弯道，形成适合畅跑的闭环：

**营地 → 暖灯雪林 → 开阔雪地 → 舒缓 S 弯 → 小雪坡 → 营地。**

- 地图保存路线、宽度、坡度和圈数检查点。
- 场景统一使用雪地美术资源，沿路线布置。
- 雪面纹理循环复用，树林、雪堆和灯柱按模块组合。
- 关键地标每圈固定，装饰通过多组资源减少重复感。
- 起终点连接自然，完成第三圈后平滑减速进入结算。

三圈共用路线，让热情逐步累积。初步按每圈约 45～60 秒设计，试玩后调整。

## 六、实施顺序与验收

| 阶段 | 工作 | 通过标准 |
| --- | --- | --- |
| 1. 确认设计与设备条件 | 确认构图、犬队比例、子板配置、屏幕和资源预算 | 视觉方向明确，操作映射可执行 |
| 2. 静态视觉样片 | 制作正常奔跑与高分撒欢两张效果图 | 六犬三排清楚，配色和质感贴近参考 |
| 3. 最小动态场景 | 一段直道、一个弯，加入犬队循环、牵引绳和雪橇运动 | 已经能感受到“狗狗欢快拉着我跑” |
| 4. 操作与热情反馈 | 接入转向、IMU、跳跃、刹车和分数变化 | 操作顺滑，低速到高速的反馈连贯 |
| 5. 完整三圈 | 闭环路线、场景复用、圈数和结算 | 能完整跑完三圈，无明显场景接缝 |
| 6. 模拟器与真机验证 | 检查性能、输入延迟、可读性和长时间运行 | 真机稳定运行，犬队清晰，风雪增强时仍好控制 |

技术路线在设备预算确认后选择，重点比较分层透视场景与轻量三维方案。先验证犬队动画和转弯透视，再投入完整地图资源。

## 第一版验收重点

六只狗狗在前面跑得特别开心，玩家扶着雪橇，蓝色雪林和暖灯从两侧掠过，风雪迎面而来，玩家也跟着它们兴奋起来。
